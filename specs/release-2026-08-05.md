# 发布手册 · 2026-08-05（v1.1.0 提审版）

本版目标：学习伙伴真实交互（DeepSeek 云端对话）、知识库迁移到服务端私有接口、点亮/迁移庆祝动效，完成提审上架。

## 一、本次改动清单

### 云端（cloudfunctions/）
- 新增 `knowledgePack`：知识库分页私有接口。125 篇《机器人产品内参》索引（485 chunks）只存在于云函数包内，客户端按页拉取（每页 160 条，共 4 页）。
- 新增 `studyChat`：学习伙伴对话 Agent。服务端检索相关知识片段 → DeepSeek（`deepseek-v4-flash`，JSON 输出）生成针对问题的回答 + 追问 + 2-3 个动态建议问题；无密钥或调用失败时返回 `mode: "fallback"`，客户端自动降级。
- 两个函数均已通过本地逻辑冒烟测试（分页、检索 grounding、错误分支）。

### 小程序端（miniprogram/）
- 客户端已删除 `knowledge/robot-product-internal.*`（约 700KB 内参副本），包体从 ~1.1MB 降至 452K。
- 新增 `knowledge/fallback-knowledge.ts`：8 条团队自写离线摘要（不含内参原文），断网/云未就绪时兜底，界面明确标注"离线模式"。
- 新增 `services/knowledge-service.ts`：内存 → 本地缓存 → 云端分页拉取的三级知识库就绪流程。
- 聊天页（pages/agent）：
  - 云端优先：发送 → "小响正在翻知识库…"打字动效 → DeepSeek 针对问题的真实回答 → 动态建议追问 chips（点击即问）。
  - 每条回复标注来源（云端回复 / 离线模式）与知识依据条数。
  - 学习伙伴人设"小响"：头像呼吸动效、口语化欢迎语。
- 费曼页：首次点亮拼图时全屏撒花庆祝层（纯 WXSS，无图片资源）；案例页首次迁移成功同样有庆祝层。
- 掌握判定、点亮规则全部保持本地确定性逻辑，模型只负责讲解，不参与判定。

## 二、部署步骤（已完成 ✅ 2026-08-06）

> 最终采用腾讯云 `tcb` CLI 部署（开发者工具的云开发面板对当前账号不可用）：
> - 使用自己的 CloudBase 环境 ID 部署 `knowledgePack` 与 `studyChat`，再逐一远程验证。
> - `npx tcb fn invoke` 远程验证：`knowledgePack` 返回 125 篇 / 485 chunks；`studyChat` 配好 `DEEPSEEK_API_KEY` 后返回 `mode: "deepseek"` 的真实回答
> - 小程序代码已通过 `cli upload` 上传为开发版本 **v1.1.0**（主包 179KB）
>
> 以后更新函数或代码都走这两条命令，无需再开 DevTools 云开发面板。
