# 身知回响 P0/P1：个人学习中心与项目学习 Agent

## 主流程

```text
我的 → 我的项目 → 选择 PDF/DOCX/MD/TXT
→ 阅读数据说明并确认
→ 临时上传 CloudBase
→ 云函数解析文本
→ 程序遍历全文并按位置提取多维证据
→ DeepSeek 重组因果、依赖、取舍、风险与缺口（失败则规则降级）
→ 删除临时文件
→ 展示可展开项目图谱、智能洞察、节点原文证据、学习目标和项目题目
→ 本地保存生成结果
```

无项目时：`我的项目 → 通用学习入口 → 知识导图/学习伙伴`。

## Agent 可观察步骤

1. Context：判断当前使用项目知识还是通用知识。
2. Retrieve：项目模式解析上传文件；通用模式检索内置知识库。
3. Plan：生成学习目标和学习顺序。
4. Act：调用 DeepSeek JSON Output；不可用时执行规则降级。
5. Verify：校验输出结构、题目依据和边界。
6. Remember：只在当前设备保存计划、收藏和最近学习。

## v1.2.4 闭环补强（2026-08-09）

```text
选择文件 → 四字符以内的有效确认弹窗
→ 上传 / 临时地址 / 分析三阶段状态与超时预算
→ 结构校验与规则降级
→ 临时文件删除确认（失败可见）
→ 项目计划交付
→ 围绕结构化项目计划问小响
→ 项目题目确定性验证
→ 失败后原题定向重答
→ 每题答案、证据、尝试次数、完成状态、下一步本地沉淀
→ 对话“有帮助 / 换种讲法”反馈进入本地台账，负反馈触发针对性修复
```

外部状态预算：上传 20 秒、临时地址 12 秒、项目云函数客户端等待 65 秒、临时文件删除 10 秒。云函数内部下载 15 秒、模型首轮 25 秒并允许一次 14 秒重试；`studyChat` Agent 总预算 52 秒，保持在 CloudBase 60 秒函数上限内。

### 智能图谱展示

- 全文先按段落和约 4500 字文本块遍历，不再只把开头一段交给模型；返回字符、段落、文本块和证据块覆盖指标。
- 规则层从背景、用户、目标、流程、需求、方案、约束、风险、指标、决策/缺口十个维度建立带位置证据摘要。
- 模型层输出 WHY / WHAT / HOW / VERIFY 多层关系、决策 / 风险 / 缺口 / 指标洞察和基于项目证据的问题。
- 模型返回部分有效 JSON 时保留有效推理，并用确定性全文证据补齐缺项；只有模型完全无有效贡献时才标记规则降级。
- 界面支持洞察筛选、分支展开/收起、节点聚焦、原文证据下钻；分析雷达、扫描线、覆盖进度、图谱轨道与连线流动、节点展开、完成庆祝均支持 reduced-motion。
- 展示前统一清洗 Markdown 标题、列表/引用标记、装饰括号、Emoji 与特殊符号，并过滤明显的口头禅和无信息量对话。
- 节点正文使用 Agent 归纳的简短结论，不拼接多段原文；每个节点最多保留三条压缩后的“依据摘要”，用于可解释追溯。
- 私人关系话术、保密闲聊、聊天角色标签和“文章中出现了什么”一类文档元问句在证据评分前直接屏蔽，不发送给模型。
- 项目首页摘要由 Agent 从本次导入材料中提取，只回答“项目是什么、面向谁、解决什么、要实现什么”；不得写成文档复述，也不得调用通用知识库补写项目事实。
- 项目身份默认匿名：客户端只发送 `个人项目.<扩展名>`，界面固定显示“个人项目 / 原文件名已隐藏”；文档封面标题及显式项目名称在进入模型前替换为“个人项目”。
- 旧本地计划读取时自动迁移，真实标题、文件名及常见去后缀简称会在摘要、图谱、证据、洞察、题目和小响上下文中统一替换。

项目对话只发送已经过结构校验的标题、摘要、目标和分支，不发送或持久化原始文件。小响必须区分“项目计划明确内容”和“通用机器人产品建议”，不得声称仍能读取已经删除的原文件。

## 数据边界

- 不读取微信头像、昵称、手机号或通讯录。
- 不允许小程序携带 DeepSeek API Key。
- 上传前提醒移除密码、API Key、合同敏感信息和个人信息。
- 文件上限 10 MB，仅允许 PDF、DOCX、Markdown、TXT。
- CloudBase 文件仅用于本次解析，小程序在云函数返回或失败后立即尝试删除。
- 项目原文不写入本地持久化；仅保存结构化学习结果。

## DeepSeek 配置

- CloudBase 云函数环境变量：`DEEPSEEK_API_KEY`。
- 可选：`DEEPSEEK_MODEL`，默认 `deepseek-v4-flash`。
- API：`POST https://api.deepseek.com/chat/completions`。
- 响应模式：`response_format: { "type": "json_object" }`。
- 任何响应均先做结构校验，再返回小程序。
