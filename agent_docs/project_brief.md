# Project Brief

- **Product vision:** Let learners see, understand and prove each missing piece of a complex professional knowledge map; begin with embodied-intelligence product management.
- **Target Audience:** C-level learners with some coding/product foundation who need structure, deep understanding and real-work transfer.

## Conventions
- **Naming:** kebab-case files, PascalCase React components, camelCase functions and variables, UPPER_SNAKE_CASE environment variables.
- **File Structure:** Use feature-oriented component folders; keep curated content in `src/content`, Agent/provider code in `src/lib/agent`, deterministic mastery in `src/lib/mastery`, schemas in `src/lib/schemas`, and persistence behind `src/lib/storage`.

## Key Principles
- Ship the simplest complete learning loop, not the largest content library.
- The map comes before chat; the Agent supports a structured learning journey.
- Show evidence before rewards. Every mastery state must be explainable.
- Let the learner attempt before hints or reference answers.
- Treat “complete map” as a versioned role boundary with sources, not a claim to contain an entire changing industry.
- Keep the demo usable without external services and label degraded behavior honestly.
