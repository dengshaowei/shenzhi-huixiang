# Product Requirements

## Product Summary
- **Product:** 具身拼图
- **One-liner:** An evidence-backed AI learning Agent that turns embodied-intelligence product competency into a visible, learnable and verifiable puzzle.
- **Target users:** Intermediate product/technical learners who have seen embodied-intelligence concepts but cannot judge their coverage or apply them reliably.

## User Stories
- As an embodied-intelligence learner, I want a role-based knowledge map so that I know what to learn and which gaps remain.
- As a learner, I want to explain a concept in my own words and receive evidence-based feedback so that I know whether I truly understand it.
- As an aspiring product manager, I want to apply a learned concept to a constrained robot case so that I can prove transfer to real product work.
- As a returning learner, I want each unlocked node to show its evidence so that progress feels trustworthy rather than arbitrary.

## Feature List (MoSCoW)

### Must Have
- [ ] Interactive nine-domain competency puzzle with four mastery states
- [ ] Detailed “感知与传感器 → 传感器选择” mind map and visual micro-lesson
- [ ] Constraint-based mini-game and Feynman explanation Agent
- [ ] Explainable mastery evidence, deterministic unlock and next-step recommendation
- [ ] Bounded warehouse robot product-analysis transfer task

### Should Have
- [ ] Responsive focused/list view for mobile graph navigation
- [ ] Model-provider adapter with a clearly labeled no-key fallback evaluator
- [ ] Source and curriculum-version display on relevant content

### Could Have
- [ ] Lightweight event analytics for the core funnel
- [ ] Additional preset learner responses for live demonstrations

### Won't Have (this version)
- Complete courses for all nine domains; user document upload; automatic PRD generation; multi-agent orchestration; full RAG; accounts, payment, social features; complete A/B learner paths.

## Success Metrics
- At least 4 of 5 target testers complete the whole flow without human instruction.
- At least 4 of 5 testers can state why a node was or was not unlocked.
- End-to-end experience takes 8–15 minutes and has no blocking errors.
- At least 60% of initially failed rubric dimensions improve on the second attempt.

## Out of Scope
- Do not add dynamic curriculum generation, unreviewed knowledge nodes, a database, auth, uploads, payments, social mechanics, or multiple autonomous agents during the two-day MVP.
