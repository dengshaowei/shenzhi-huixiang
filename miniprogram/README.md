# 身知回响微信小程序复现说明

这是微信原生 TypeScript 小程序。没有云服务时，核心学习路径仍可使用本地课程、公开示例知识和确定性规则运行。

## 导入

1. 安装微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录，而不是单独选择 `miniprogram/`。
4. 将 `project.config.json` 中的 `your-appid` 替换为自己的小程序 AppID或测试号。
5. 占位 AppID 不能直接编译；替换后点击“编译”。

## 核心体验路径

1. 进入“知识导图”，查看四组九域能力地图。
2. 进入“感知与传感器”。
3. 阅读传感器选择微课。
4. 完成仓储 AMR 方案挑战。
5. 提交费曼复述并根据五维反馈重试。
6. 达标后点亮节点，再进入机器人案例完成迁移。

示例复述：

> 仓库通道窄、货架遮挡且光照会变化。激光雷达提供稳定测距，相机负责识别工作人员，两者互补，并保留近距防撞作为安全冗余。这样会增加成本和算力，但能降低人员混行时的避障风险。

## 启用自己的云环境

1. 创建微信小程序和CloudBase环境。
2. 用自己的小程序AppID替换根目录 `project.config.json` 中的 `your-appid`。
3. 用自己的环境ID替换 `config/cloud.ts` 中的 `your-cloudbase-env-id`。
4. 按 [CloudBase部署说明](../docs/CloudBase-部署说明.md) 部署云函数。
5. 模型密钥只写入云函数环境变量，禁止写入小程序代码。

公开包中的云函数知识库是最小示例，不包含原项目私人资料。

## 本地验证

在仓库根目录运行：

```bash
npm install
npm test
npm run lint
npm run typecheck:mini
```

微信页面的最终编译、文件选择和真机交互需要在微信开发者工具及真实设备上验证。
