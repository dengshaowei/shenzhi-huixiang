# Project Brief

- **Product vision:** Make embodied-intelligence product competence visible, learnable and provable in short WeChat learning sessions.
- **Target Audience:** Intermediate product and technical learners with fragmented embodied-intelligence knowledge.

## Conventions

- **Naming:** kebab-case files, PascalCase types, camelCase functions.
- **File Structure:** Pages by route; pure domain logic in `core/`; WeChat API boundaries in `services/`.

## Key Principles

- Ship one complete learning branch, not nine incomplete courses.
- Curated content defines truth; feedback cannot invent curriculum facts.
- The learner answers before seeing feedback.
- Progress is awarded only for deterministic, explainable evidence.
- The full demo must work with no key and no backend.
